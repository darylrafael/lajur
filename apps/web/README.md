# Apps: Web Simulator & Dashboard

Direktori ini berisi aplikasi web Next.js untuk:
1. **Drive-thru Simulator**: Antarmuka pemesanan suara real-time berbasis WebRTC (LiveKit Client) dengan papan menu, layar konfirmasi pesanan live, transkrip percakapan, dan kontrol preset noise audio.
2. **Public Metrics Dashboard**: Menampilkan metrik latensi, Order Accuracy Rate (OAR), dan total sesi demo secara transparan.

*Status: Dibuat di Minggu 1 (Walking Skeleton) & Minggu 5 (Simulator Penuh).*
