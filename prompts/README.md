# Prompts: Versioned LLM Prompts

Direktori ini menyimpan seluruh prompt LLM yang berversi git:
- System prompt untuk parsing intent ucapan ke JSON terstruktur.
- Prompt persona bot kasir drive-thru (ramah, singkat, efisien).
- Template prompt untuk persona uji simulasi pelanggan.

Setiap perubahan prompt wajib mencatat commit hash, model LLM target, temperature, dan hasil skor evaluasi terkait.
